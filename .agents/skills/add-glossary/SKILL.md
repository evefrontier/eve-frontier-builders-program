# Add Glossary Item

This skill guides adding a new term to the curriculum glossary located at [curriculum/glossary.md](file:///home/scetrov/source/eve-frontier-builders-program/curriculum/glossary.md).

## Required Fields

Every glossary entry requires three core fields:

1. **Key (Term Heading)**: The name of the term as a Markdown level-3 header (`### Term Name`).
   - The link slug generated by the system is lowercase, with spaces converted to hyphens and punctuation removed.
   - Example: `### Smart Assembly` -> slug: `smart-assembly`.
2. **Tags (Topics Line)**: An italicized metadata line directly below the heading (`*Topic 1, Topic 2*`).
   - Must contain at least one valid topic tag, spelled exactly:
     - `Game & economy`
     - `Sui & Move`
     - `Smart Assemblies`
     - `Wallet & identity`
     - `dApps & tools`
   - Multiple topics are separated by commas, with the primary topic first.
   - **Optional modifiers** on this line:
     - Aliases: ` · also: alias1, alias2`
     - Suppression of auto-highlighting in lessons: ` · no highlight`
3. **Description (Definition)**: A 1–3 sentence plain text paragraph explaining the concept in builder-facing terms.
   - Per repository guidelines, keep definitions plain and concise. Avoid duplicate copy by linking to canonical sources.

## Optional Fields

- **Official Docs Link**: Direct link to external documentation (e.g., Sui docs):
  ```markdown
  [Read more in the Sui Docs →](https://docs.sui.io/...)
  ```
  *(Must start with `Read more in the ` and end with ` Docs →`, URL must start with `https://`)*
- **Deep-Dive Article Link**: When a term warrants a multi-section explanation:
  ```markdown
  [Read the article →](glossary/<slug>.md)
  ```
  *(Requires corresponding article at `curriculum/glossary/<slug>.md` and an entry in `curriculum/SUMMARY.md`)*

## Canonical Format Example

Entries are grouped alphabetically under level-2 headings (`## A` through `## Z`, or `## #` for symbols):

```markdown
## E

### Epoch

*Sui & Move*

A fixed period of about 24 hours on Sui during which the set of validators, and the reference gas price, stays the same. When an epoch ends, the network moves to the next one, updating validators, staking rewards and gas pricing.

[Read more in the Sui Docs →](https://docs.sui.io/develop/sui-architecture/epochs)
```

## Step-by-Step Procedure

1. **Locate Letter Group**: Open `curriculum/glossary.md` and find the matching `## <Letter>` section (or create it if it doesn't exist).
2. **Insert Alphabetically**: Place the new `### <Key>` block in alphabetical order within that letter section.
3. **Format Topics & Modifiers**: Add the `*Tags*` line with one or more valid topic names.
4. **Draft Description**: Provide the 1–3 sentence description.
5. **Verify**:
   - Run type checks and linter:
     ```bash
     cd web && ./node_modules/.bin/oxlint && ./node_modules/.bin/tsc --noEmit
     ```
   - Ensure the definition parses correctly and references valid topics.
