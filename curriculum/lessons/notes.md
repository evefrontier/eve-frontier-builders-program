# Ask it to keep notes

```markdown title="AGENTS.md · Ground rules"
- Ask before deleting anything.
- Explain changes in plain English.
- Test on a copy of the world before anything goes live.
```

Your ground rules. Many AI agents look for a file with this name at the start of every chat.

```markdown title="decisions.md · Decision log"
- 22 Oct: The safe list is one the owner edits, not the whole tribe. Owner wants to add allies.
- 23 Oct: Built for the current world contracts. The next version changes how rules attach; revisit then.
```

Each decision, when it was made, and why.

Ask your AI to keep these two files up to date. Every new chat starts by reading them, so it follows your rules, picks up where you left off, and can tell you why something was done the way it was.
