# Which AI do you have?

```question
ask: tool
```

```by-answer
answer: tool
variants:
  none: |-
    **Got it.** Start with the free version of any chat app. Then ask it to search the web for which AI tools are best for building right now, because the answer keeps changing.

    **When to step up:** Once you've tried a few ideas, a chat app is your first rung.
  chat: |-
    **Got it.** You'll copy and paste between the chat and your files, unless you connect it to GitHub.

    **When to step up:** When copying gets tedious, step up to an app that works on your files.
  desktop: |-
    **Got it.** It opens, changes and runs files in a folder you choose. Give it ground rules before it starts.

    **When to step up:** When you want test links, GitHub and the agent in one window, step up to a code editor.
  editor: |-
    **Got it.** The most capable setup on your own computer: the agent edits, runs, tests and saves checkpoints.

    **When to step up:** When you want to hand off a job and check it later, even from your phone, try agents in the cloud.
  cloud: |-
    **Got it.** Agents work on your GitHub project and send you changes to approve. You need a project on GitHub first.

    **When to step up:** You're at the top. Most people mix rungs: the cloud for small jobs, an editor for big ones.
```
