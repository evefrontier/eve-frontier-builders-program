# You're ready

## Here's what you now know

- You direct; AI agents write, run and check the code. You never need to learn to code.
- Every build goes round the loop: describe, plan, build, prove, save.
- Tell your AI where to look, and get it to keep notes.
- Look at the result yourself, and keep it safe, cheap and running.

## One way to start

```prompt
label: You might say
copy: true
text: '{{idea.want|I want to build something new for EVE Frontier.}} [[It''s {{audience.phrase}}.]] [[{{tool.phrase}}, and ]]I don''t write code. [[{{tool.extra}} ]]Before you build anything, find and read the official EVE Frontier builder docs written for AI and the world contracts on GitHub, including the next version on the dev branch, and tell me if anything I want isn''t possible. ```
```
