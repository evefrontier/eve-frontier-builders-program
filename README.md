# EVE Frontier Builders Program

The EVE Frontier Builders Program is an always-on learning and activation path for people who want to build within EVE Frontier — one program, multiple entry points, shared tools and standards.

This repo is a starting point. It covers process and structure, not the curriculum itself, and it's expected to change as the builder community and the program grow.

## Scope

This repo owns the program's pillar structure, shared tooling references, builder-facing documentation, and contribution process — not the products builders build (see the [evefrontier organization](https://github.com/evefrontier) for those). The full approved scope for Layer 1 is at [docs/scope.md](docs/scope.md).

## Program Structure

Five connected pillars, each building on the last — see [docs/entry-points.md](docs/entry-points.md):

0. Frontier Builder Foundations
1. Agentic Coding and Low Code for EVE Frontier
2. Frontier Systems & World Interaction
3. Move & Sui
4. Move & Sui in the Context of EVE Frontier

**GitBook** is the primary learning surface for the actual curriculum, kept in sync with a docs repo via Git Sync. This repo is the process layer, not a second copy of the lessons.
