# EVE Frontier Builders Program

The EVE Frontier Builders Program is an always-on learning and activation path for people who want to build within EVE Frontier.

One program, multiple entry points, shared tools and standards. Whether you are taking your first steps or are an experienced builder, the program provides a path from first contact to building and deploying within EVE Frontier.

## Scope

This repo owns:

- the program curriculum and learning paths;
- the entry-point tracks for different builder backgrounds and experience levels;
- shared tooling and standards guidance for builders (including references to ecosystem packages such as [`@evefrontier/component-library`](https://github.com/evefrontier/eve-frontier-component-library/pkgs/npm/component-library));
- builder-facing documentation;
- program governance and contribution process.

It does not own the products builders ultimately build. For product-specific repos, see the [evefrontier organization](https://github.com/evefrontier).

## Program Structure

The program is organized as a single path with multiple entry points, so builders can join at the stage that matches their experience:

- **First Contact** — orientation to EVE Frontier, its on-chain foundations, and the builder ecosystem.
- **Core Path** — shared tools, standards, and workflows every builder uses regardless of track.
- **Build & Deploy** — hands-on tracks for shipping tools, dapps, and integrations within EVE Frontier.

See [docs/entry-points.md](docs/entry-points.md) for details on each track and how to choose one.

## Community

Real-time builder chat happens on the [EVE Frontier Discord](https://discord.gg/CSnU8e6FC) — specifically the [builders channel](https://discord.com/channels/1021714190102175754/1316697380069969930). That's the fastest way to ask questions, get unstuck, and hear what other builders are working on. GitHub Issues and Discussions on this repo are for tracked, written-down feedback (see [Contributing](#contributing)).

## Related Repositories

This program is part of the broader EVE Frontier builder ecosystem:

- [dapp-index](https://github.com/evefrontier/dapp-index) — registry and discovery for Frontier dapps
- [builder-scaffold](https://github.com/evefrontier/builder-scaffold) — templates and tools to build in EVE Frontier
- [builder-documentation](https://github.com/evefrontier/builder-documentation) — reference documentation for third-party development
- [eve-frontier-component-library](https://github.com/evefrontier/eve-frontier-component-library) — shared UI component library for builder-facing apps

See the full list at [github.com/orgs/evefrontier/repositories](https://github.com/orgs/evefrontier/repositories).

EVE Frontier itself runs on [CARBON Engine](https://github.com/carbonengine), the open-source game engine powering EVE Online and EVE Frontier's persistent sandbox worlds.
